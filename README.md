# 年会抽奖（控制台分离版）

现在是独立 4 页面：

- `index.html`：配置页面（奖品、员工、主题、生成二维码）
- `wheel.html`：转盘抽奖页面（按奖品概率/库存抽奖）
- `employee.html`：抽员工展示页面（大屏舞台效果，可设轮次和每轮人数）
- `employee-control.html`：抽员工控制台（主持人操作：开始/停止/重抽/回退/导出）

## 支持能力

- 3 套主题切换：国潮舞台 / 赛博霓虹 / 黑金颁奖（在配置页切换）
- 员工名单支持手动输入 + Excel/CSV 导入
- 本机预览按钮可直接跳转到独立抽奖页面
- 奖品支持“几等奖 + 奖品名称(可空)”，名称为空时自动显示“几等奖”
- 转盘概率模式支持 2 种：
  - 权重模式（当前模式）
  - 百分比模式（各奖项百分比总和必须=100）
- 转盘页支持员工身份校验与“每人仅中奖一次”
- 抽员工页轮次来自配置页：每个奖项可配置“每轮固定人数”或“总人数+轮次”
- 抽员工页支持手动追加员工、记录导出
- 抽员工支持“控制台 + 展示页”分离，方便主持人和大屏分别打开
- 配置页支持导出：转盘中奖记录 CSV、抽员工记录 CSV
- 配置页可生成“每轮抽员工独立链接”（`employee.html?step=N`），方便嵌入 PPT
- 配置页可生成“每轮控制台独立链接”（`employee-control.html?step=N`），方便主持人按轮次推进

## 快速运行

```bash
cd /Users/yanko/space/project/youyo-discount
python3 -m http.server 8080
```

打开：

- 配置页：`http://localhost:8080/index.html`

## 使用流程

1. 在配置页填奖品与员工名单。
2. 选择概率模式（权重 / 百分比100）并配置每个奖项的抽员工规则。
3. 选择主题（会随链接带到抽奖页）。
4. 点击生成“转盘页链接”或“抽员工页链接”。
5. 现场可直接“本机预览”，或让员工扫码进入。

## 员工导入格式

- 推荐表头：`工号,姓名`（也支持 `id,name`）
- 无表头默认按前两列读取
- 仅读取第一个工作表

## 数据说明

- 当前为无后端版本，数据保存在浏览器 `localStorage`。
- 同一浏览器/设备可持续使用库存和记录。
- 换设备后数据不共享。
